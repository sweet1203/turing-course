  • 웹 앱 주소 복사하기

    배포가 끝나면 웹 앱 URL이 나옵니다. 복사를 눌러 메모장에 붙여 두세요.

    https://script.google.com/macros/s/AKfy…긴 글자…/exec

    ✔ 주소 끝이 /exec여야 합니다. (/dev로 끝나는 주소는 선생님만 쓸 수 있는 테스트 주소예요.)

  • 이 페이지에서 연결 테스트하기

    바로 아래 ③ 연결 테스트에 주소를 붙여 넣고 연결 확인 → 테스트 제출을 눌러 보세요. 시트의 해당 차시 탭에 테스트 줄이 생기면 성공입니다.

  • 사이트에 주소 넣기 (js/config.js)

    사이트 파일 중 js/config.js를 열어 APPS_SCRIPT_URL의 따옴표 안에 주소를 붙여 넣고 저장합니다.

    APPS_SCRIPT_URL: "https://script.google.com/macros/s/AKfy…/exec",

    GitHub에 올린 사이트라면: 저장소에서 js/config.js 클릭 → 오른쪽 위 ✏️ 연필 → 주소 붙여 넣기 → Commit changes. 1~2분 뒤 사이트에 반영됩니다.

    학생 화면에서 테스트로 한 번 제출해 “제출했어요!”가 나오면 끝! 🎉

교사용 안내 여는 법 (숨긴 메뉴)

학생 화면이 복잡하지 않도록 교사용 안내는 메뉴에 보이지 않게 숨겨 두었습니다. 아래 방법 중 하나로 여세요.

  • 어느 페이지에서든 왼쪽 위 로고 🤖 나만의 튜링 챗봇을 빠르게 5번 클릭
  • 입력칸이 아닌 곳을 누른 뒤 키보드로 teacher 입력
  • 주소 뒤에 직접 teacher.html을 붙여 열기

※ 숨긴 메뉴일 뿐 비밀번호는 아닙니다. 이 페이지에는 학생 정보가 없고, 학생 답은 선생님의 스프레드시트에만 있습니다.

세특 질문 답은 직접 타이핑

세특 질문 답 칸에서는 붙여넣기(Ctrl+V)와 끌어다 놓기가 막혀 있습니다. 시도하면 화면 아래에 “붙여넣기(Ctrl+V)는 제한되어 있어요.”라는 메시지가 잠깐 뜹니다. 학생이 직접 생각해서 쓰도록 하기 위한 장치입니다.

한 차시 수업 흐름 (권장)

  1. 수업 시작: 해당 차시 페이지 주소를 학생에게 공유합니다. (예: …/lesson3.html)
  2. 도입 · 개념: ‘오늘의 목표’와 ‘개념 쏙쏙’을 함께 읽습니다. 물음표 항목(▶ 펼치기)은 궁금한 학생이 스스로 엽니다.
  3. 따라 하기: 단계 옆 꼬리표를 보고 진행합니다. 나 혼자 · 모둠 함께 · 선생님 화면 교사 PC에서 진행.
  4. 서버 단계: 선생님 화면 단계는 교사가 VESSL 서버를 켜고 TV에 띄워 진행합니다. 서버는 한 번에 한 질문만 처리하므로 모둠 대표가 차례로 질문합니다.
  5. 마무리 5분: 맨 아래 세특 질문 3개를 쓰고 제출합니다.

학생 기록은 어디에 저장되나요?

  • 진행 체크 · 실습 도구 · 쓰는 중인 답: 학생 기기의 브라우저에만 저장됩니다. (서버로 가지 않음)
  • 세특 질문 제출: 선생님 스프레드시트로만 전송됩니다. 학생끼리는 서로의 답을 볼 수 없습니다.
  • 공용 PC를 쓰는 경우, 수업 끝에 세특 질문 칸의 ‘내 답 지우기’를 누르도록 안내하세요. (제출한 내용은 지워지지 않습니다.)

세특 작성에 활용하기

  • 차시 탭에서 학번 열을 정렬하면 반·번호 순으로 볼 수 있습니다.
  • 각 질문은 내가 한 일 · 원인 분석 · 개념 설명 · 생각과 태도가 드러나도록 구성했습니다. 학생 답의 구체적인 사례를 근거로 활용하세요.
  • 학번·이름은 개인정보이므로 스프레드시트 공유 설정은 제한됨(나만)으로 두세요.

⑤ 문제 해결

학생이 제출할 때 “지금은 제출할 수 없어요”라고 나와요

js/config.js의 APPS_SCRIPT_URL이 비어 있습니다. ②의 9단계를 하세요. 고친 뒤에도 그대로면 학생에게 Ctrl+F5(완전히 새로고침)를 안내하세요.

제출했다는데 시트에 줄이 없어요

① 배포 설정의 액세스 권한이 모든 사용자인지 ② 주소가 /exec로 끝나는지 ③ ③ 연결 테스트가 성공하는지 확인하세요. 학교망에서 응답을 못 받으면 학생 화면에 “확인 메시지를 받지 못했어요”가 뜨는데, 이때도 대부분 시트에는 저장됩니다.

배포 화면에 ‘모든 사용자’가 없어요 (학교 Workspace 계정)

학교 관리자가 외부 공개를 막아 둔 경우입니다. ‘○○학교 내 모든 사용자’만 보인다면 학생도 같은 학교 계정으로 로그인해야 제출할 수 있습니다. 로그인 없이 받으려면 개인 Google 계정으로 스프레드시트와 스크립트를 만드세요.

코드를 고쳤는데 반영이 안 돼요

Apps Script는 배포를 새 버전으로 바꿔야 반영됩니다. 배포 → 배포 관리 → ✏️ 연필 → 버전: 새 버전 → 배포. 이렇게 하면 주소가 그대로 유지됩니다. (‘새 배포’를 누르면 주소가 바뀌니 주의!)

세특 질문을 바꾸고 싶어요

① js/config.js의 LESSONS 질문 수정 ② Apps Script의 LESSONS 질문도 똑같이 수정 → 저장 ③ setupSheets 다시 실행(1행 제목만 바뀌고 학생 답은 그대로) ④ 위의 ‘새 버전으로 배포’.

학번 형식이 달라요 (예: 4자리, 6자리)

js/config.js의 STUDENT_ID_PATTERN(예: "^[0-9]{4,6}$")과 Apps Script의 STUDENT_ID_PATTERN(예: /^[0-9]{4,6}$/)을 같이 바꾸고 새 버전으로 배포하세요.

같은 학생이 여러 번 제출했어요

정상입니다. 같은 차시에 같은 학번이면 마지막 제출 내용으로 바뀌고 ‘제출 횟수’만 늘어납니다. 다른 학생이 학번을 잘못 써서 덮어썼다면 시트의 파일 → 버전 기록에서 되돌릴 수 있습니다.

3차시 검색 시뮬레이터가 자료를 못 불러와요

학교망에서 raw.githubusercontent.com이 막혀 있으면 자동으로 다른 주소(jsdelivr)로 다시 시도합니다. 둘 다 막혀 있다면 data.json을 사이트 폴더에 넣고 js/search.js의 DATA_URLS 맨 앞에 "data.json"을 추가하세요.
