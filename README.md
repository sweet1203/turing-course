# 🤖 나만의 튜링 챗봇 만들기 — 5차시 정보 수업 코스웨어

앨런 튜링 페르소나 챗봇을 만들고 로블록스 NPC로 연결하는 5차시 수업을, 학생이 스스로 따라가도록 만든 정적 웹사이트입니다.
수업 끝에는 차시별 **세특 질문 3개**를 제출하고, 답은 선생님의 Google 스프레드시트(1차시~5차시 탭)에 모입니다.

- AI 실습 저장소(최종본): <https://github.com/CarlosQuperman/persona-ai>
- 선생님 안내: 사이트의 **교사용 안내** 페이지(`teacher.html`) — 메뉴에 보이지 않는 숨긴 페이지입니다. 아래 [교사용 안내 여는 법](#교사용-안내-여는-법-숨긴-메뉴)을 보세요.

## 교사용 안내 여는 법 (숨긴 메뉴)

학생 화면이 복잡하지 않도록 교사용 안내는 상단 메뉴에 넣지 않았습니다. 아래 방법 중 하나로 여세요.

1. 어느 페이지에서든 왼쪽 위 로고 **🤖 나만의 튜링 챗봇**을 **빠르게 5번 클릭**
2. 입력칸이 아닌 곳을 한 번 누른 뒤, 키보드로 **`teacher`** 입력
3. 주소창에 직접 입력: <https://sweet1203.github.io/turing-course/teacher.html>

> 숨긴 메뉴일 뿐 비밀번호는 아닙니다. 이 페이지에는 학생 정보가 없고, 학생 답은 선생님의 스프레드시트에만 저장됩니다.

## 학생 답 작성 규칙

세특 질문 답 칸에서는 **붙여넣기(Ctrl+V)와 끌어다 놓기가 막혀 있어** 학생이 직접 타이핑해야 합니다. 시도하면 “붙여넣기(Ctrl+V)는 제한되어 있어요.” 메시지가 잠깐 뜹니다.

## 구성

| 파일 | 내용 |
| --- | --- |
| `index.html` | 홈 — 프로젝트 소개, 차시별 진행률, 학생용 사용법 |
| `lesson1.html` ~ `lesson5.html` | 차시 페이지 — 목표 · 개념 · 따라 하기 단계 · 실습 도구 · 세특 질문 |
| `teacher.html` | 교사용 안내(숨긴 페이지) — 스프레드시트 연결(단계별), 연결 테스트, 사이트 사용법, 문제 해결 |
| `js/config.js` | **선생님이 고치는 파일** — Apps Script 주소, 학번 형식, 차시별 세특 질문 |
| `js/common.js` | 메뉴, 진행 체크 저장, 복사 버튼, 세특 질문 폼 |
| `js/search.js` | 3차시 검색 시뮬레이터 (app.py와 같은 2글자 자르기 + BM25 + 최대 2건 규칙) |
| `apps-script/Code.gs` | 스프레드시트에 붙여 넣는 Apps Script (차시별 탭, 학번별 덮어쓰기) |
| `css/common.css` | 공통 디자인 |

## 빠른 시작 (선생님)

1. 새 Google 스프레드시트 → **확장 프로그램 → Apps Script** → `apps-script/Code.gs` 붙여 넣기 → 저장
2. `setupSheets` 실행 → 권한 허용 → 1차시~5차시 탭 생성 확인
3. **배포 → 새 배포 → 웹 앱** (실행: 나, 액세스: 모든 사용자) → `/exec` 주소 복사
4. `js/config.js`의 `APPS_SCRIPT_URL`에 주소 붙여 넣기
5. `teacher.html`의 **연결 테스트**로 확인

자세한 설명과 화면 예시는 `teacher.html`에 있습니다.

## 로컬에서 열기

```bash
python -m http.server 5500
```

브라우저에서 <http://localhost:5500> 을 엽니다. (교사용 안내의 코드 불러오기와 검색 시뮬레이터는 서버로 열어야 작동합니다.)
