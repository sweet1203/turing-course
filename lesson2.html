📚 튜링 자료집 data.json 만들기

튜링의 ‘기억’이 될 자료를 정확하게 정리해요.

🎯 오늘의 목표

  • 페르소나에 필요한 자료를 고르고 출처를 확인해 모을 수 있다.
  • 모은 자료를 id · content · keywords 구조의 JSON으로 정리할 수 있다.
  • 검색이 잘 되도록 자료마다 핵심 키워드를 뽑을 수 있다.
도입자료 없이 vs 자료와 함께 답한 결과 비교
→
전개주제 나누기 → 3인칭 문장 → 키워드 → 검사
→
정리문서 1건 발표, 출처의 중요성

💡 개념 쏙쏙

🗂️JSON

{"이름": 값} 모양으로 자료를 정리하는 형식. 파이썬 딕셔너리와 거의 똑같아요.

🧾문서 한 건 = 3칸

id 번호 · content 사실(3인칭 2~3문장) · keywords 검색어 5~10개

✅좋은 자료의 조건

① 한 문서에 한 주제 ② ‘그는 ~했다’ 3인칭 ③ 친구들이 물을 법한 키워드

🍳 비유: 자료집은 튜링의 요리 재료예요. 재료가 상하면(틀리면) 아무리 좋은 요리사(AI)도 맛있는 요리(정확한 답)를 못 만들어요.

실제 data.json의 문서 한 건

{
  "id": "T09",
  "content": "장거리 달리기를 즐겼다. 마라톤 기록은 약 2시간 46분이었고, 1948년 올림픽 대표 선발에 도전했지만 부상으로 뜻을 이루지 못했다.",
  "keywords": ["운동", "달리기", "마라톤", "육상", "올림픽", "취미", "체력", "건강", "기록"]
}
왜 ‘그는 ~했다’처럼 3인칭으로 써요?

app.py는 자료를 튜링에게 건네며 “자료의 ‘그’는 나 자신이다”라고 알려 줘요. 3인칭으로 써 두면 튜링이 자기 이야기로 자연스럽게 바꿔 말해요. ‘나는’으로 쓰면 학생 이야기인지 튜링 이야기인지 헷갈려요.

keywords는 어디에 쓰여요?

자료를 찾을 때만 쓰여요. AI에게 건네지는 건 content뿐이에요. 친구가 “선생님 운동 좋아하세요?”라고 물으면, content에 ‘운동’이 없어도 keywords의 ‘운동’ 덕분에 T09를 찾을 수 있어요.

👣 오늘 따라 할 단계

  • 자료가 있을 때와 없을 때 비교 보기 선생님 화면

    같은 질문에 튜링이 자료 없이 답할 때와 자료를 보고 답할 때 무엇이 다른지 관찰해요.

  • 조사 노트를 주제별로 나누기 모둠

    생애 · 학창 시절 · 업적 · 취미 · 생각과 어록… 한 문서에 한 주제씩! 문서 번호(id)도 정해요.

  • 아래 도구로 문서 쓰기 나

    content는 3인칭 2~3문장, keywords는 친구들이 실제로 쓸 말 5~10개. 날짜·장소·인물은 출처와 다시 대조해요.

  • JSON 검사기로 형식 확인하기 모둠

    모둠 문서를 모아 검사기에 붙여 넣고, 오류가 없을 때까지 고쳐요.

  • 선생님께 모둠 data.json 보내기 선생님 화면

    선생님이 서버에서 python persona-core/app.py를 실행하면 첫 줄에 참고 자료 N건이 나와요. 우리 문서 수만큼 늘었다면 성공!
