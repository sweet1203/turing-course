🤖 나만의 튜링 챗봇 만들기

1952년의 앨런 튜링을 AI로 되살려, 로블록스 게임 속에서 대화해 봐요!

🤔 우리는 무엇을 만들까요?

앨런 튜링은 “기계는 생각할 수 있을까?”라는 질문을 처음 던진 영국의 수학자예요. 컴퓨터의 원리(튜링 기계)를 세웠고, 오늘날 AI를 평가하는 ‘모방 게임’을 제안했어요.

우리는 5차시 동안 AI에게 “너는 1952년 3월 31일 아침의 앨런 튜링이야”라는 역할을 주고, 튜링의 삶을 담은 자료집을 만들어, 우리 모둠만의 튜링 챗봇을 완성해요. 마지막에는 그 챗봇을 로블록스 게임 속 NPC로 연결해요.

🎮 완성하면 이런 대화가 돼요
나: 튜링 테스트가 뭐예요?
튜링(NPC): 그런 이름은 처음 듣지만 내 모방 게임을 말하는 것 같구나. 글로만 대화해서 상대가 사람인지 기계인지 맞히는 놀이야.

🌟 이 수업을 마치면 이런 힘이 생겨요

🧠AI가 답을 만드는 원리를 알아요

AI가 자료를 찾아보고 답하는 과정(RAG)을 직접 확인하면서, 챗봇이 어떻게 말을 만드는지 설명할 수 있어요.

📚자료를 모으고 정리하는 힘

출처를 확인하며 조사하고, 컴퓨터가 읽을 수 있는 data.json으로 정리해요. 좋은 자료가 좋은 AI를 만든다는 걸 알게 돼요.

🔍AI의 말을 확인하는 눈

AI가 그럴듯하게 지어낸 말(환각)을 찾아 근거와 비교해요. 앞으로 어떤 AI를 쓰든 그대로 믿지 않고 확인하는 습관이 생겨요.

🔧문제를 찾아 고치는 경험

검증 질문 → 기록 → 수정 → 재검증으로 정답률이 올라가는 걸 직접 보며, 근거를 갖고 더 나아지게 만드는 방법을 배워요.

🎮내가 만든 AI를 게임 속에서

우리 모둠의 튜링을 웹 채팅과 로블록스 NPC로 공개하고, 친구들과 대화하며 서로 평가해요.

⚖️AI와 함께 사는 법을 고민해요

실존 인물을 흉내 내는 AI의 책임과 사생활 문제를 이야기하며, 사람과 AI가 함께 살아갈 방법을 내 생각으로 말할 수 있어요.

📝 차시마다 쓰는 세특 질문 3개는 내가 무엇을 배우고 어떻게 생각했는지 보여 주는 기록이 돼요. 내 말로 솔직하게 써 보세요!

🧩 걱정 마세요! 어려운 건 선생님이 해요

AI 모델은 아주 큰 컴퓨터(GPU)에서 돌아가요. 이 컴퓨터를 켜고 서버를 실행하는 일은 선생님 화면에서 해요. 우리는 설계하고, 자료를 쓰고, 질문하고, 고치는 일에 집중하면 돼요.

🙋우리가 하는 일

튜링 조사 · 설계도 쓰기 · 자료집(data.json) 만들기 · 질문하고 답 판정하기 · 고친 내용 확인 · 서로 평가

🧑‍🏫선생님이 하는 일

GPU 컴퓨터(VESSL) 켜기 · AI 모델 서버 실행 · 모둠 파일 적용 · 웹 채팅과 로블록스 화면 띄우기

🖥️화면에 표시된 꼬리표

📌 이 사이트 사용법

  1. 선생님이 알려 준 차시 페이지를 열어요. (위쪽 메뉴의 1~5차시)
  2. 각 단계를 마치면 오른쪽의 ‘다 했어요’를 체크해요. 진행률이 저장돼요.
  3. 페이지 안의 실습 도구로 직접 해 봐요. 쓴 내용은 이 기기에 자동 저장돼요.
  4. 수업 끝에는 맨 아래 📝 세특 질문 3개에 답하고 제출하기를 눌러요.
🔒 학번·이름·답은 선생님의 스프레드시트에만 저장되고 친구들에게는 보이지 않아요. 다시 제출하면 마지막 내용으로 바뀌어요.
